# Рекомпозиция — личный дашборд

Одностраничный статический сайт для GitHub Pages.

## Публикация
1. Создай репозиторий.
2. Положи `index.html` в корень `main`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` / `/root`.

## Данные
Сейчас данные встроены прямо в HTML, поэтому Google Sheet не нужно делать публичным. После закрытия дня можно обновлять HTML новым коммитом.

Следующий этап — вынести данные в отдельный `data.json`, а затем при желании подключить безопасный автоматический экспорт из отдельного листа `Site Export` через Google Apps Script или GitHub Actions. Не стоит публиковать master Google Sheet целиком: в нём есть лишние и потенциально приватные данные.

## Про дефицит и «граммы жира»
На сайте используется настраиваемая база поддержки (по умолчанию 2600 ккал). Показатель граммов — лишь теоретический энергетический эквивалент `|баланс| / 7700 * 1000`, а не измерение фактически потерянного/набранного жира.
